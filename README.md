# بوابة الدلتا للمقاولات

تطبيق محلي لإدارة العملاء والعقود والمبالغ والمصروفات والمستندات والمرفقات. يتكوّن من واجهة React/TypeScript وخادم Express، ويخزّن البيانات في ملفات JSON محلية.

> **مهم قبل الاستخدام:** هذه النسخة توثّق السلوك الموجود في المشروع ولا تعني أن الخادم جاهز لاستضافة عامة. حماية الأدوار موجودة في الواجهة فقط، كما أن الخادم يتصل بخدمة ترخيص خارجية يمكنها حذف مجلد البيانات المحلي عند إرجاع حالة الإيقاف. راجع [ملاحظات الأمان](docs/SECURITY.md) قبل تشغيل بيانات حقيقية أو إتاحة الخادم على الإنترنت.

## البدء السريع على Windows

### المتطلبات

- Node.js بإصدار يدعم الاعتماديات الحالية، و npm.
- PowerShell.

### تثبيت الاعتماديات

من جذر المستودع:

```powershell
npm install
```

### إنشاء المدير الأول وتشغيل الخادم

في نافذة PowerShell نفسها، اختر اسمًا وكلمة مرور فريدة لا تقل عن 12 حرفًا:

```powershell
$env:INITIAL_ADMIN_USERNAME = "admin"
$env:INITIAL_ADMIN_PASSWORD = "<كلمة مرور قوية وفريدة>"
$env:INITIAL_ADMIN_NAME = "مدير النظام"
npm start
```

افتح <http://localhost:3000>. يُنشئ أول تشغيل `data/db/delta_users.json` ويخزّن كلمة المرور مجزأة باستخدام bcrypt. بعد إنشاء ملف المستخدمين، لا تعيد متغيرات التهيئة إنشاء الحساب أو تغييره.

### بناء واجهة React

```powershell
npm run build
npm start
```

يبني الأمر الواجهة في `frontend/dist`. إذا لم يوجد هذا المجلد، يقدّم الخادم الواجهة القديمة الثابتة من `client/`.

## التطوير

```powershell
# الخادم مع إعادة تشغيل عند التغيير
npm run dev

# خادم Vite للواجهة في نافذة أخرى
npm run dev:ui
```

خادم الواجهة يعمل افتراضيًا على المنفذ 5173، ويحوّل `/api` و`/files` إلى الخادم على المنفذ 3000. إعداد الوكيل في [vite.config.ts](frontend/vite.config.ts).

## إعدادات البيئة

| المتغير | مطلوب | الافتراضي | الغرض |
|---|---:|---|---|
| `PORT` | لا | `3000` | منفذ خادم Express. |
| `INITIAL_ADMIN_USERNAME` | عند تهيئة قاعدة المستخدمين فقط | لا يوجد | اسم المدير الأول. |
| `INITIAL_ADMIN_PASSWORD` | عند تهيئة قاعدة المستخدمين فقط | لا يوجد | كلمة مرور المدير الأول؛ 12 حرفًا على الأقل. |
| `INITIAL_ADMIN_NAME` | لا | قيمة اسم المستخدم | الاسم المعروض للمدير الأول. |
| `VITE_API_URL` | لا | عنوان نسبي من نفس الأصل | عنوان API الذي تستخدمه الواجهة المبنية. |
| `VITE_PUBLIC_BASE` | لا | `/` | المسار الأساسي عند نشر الواجهة داخل مسار فرعي. |

تُقرأ متغيرات `VITE_*` أثناء بناء الواجهة. لا تضع كلمات مرور أو أسرارًا في أي متغير `VITE_*`، إذ تُضمّن قيمها في ملفات المتصفح. يمكن استخدام [frontend/.env.example](frontend/.env.example) كمرجع، لكن لا تضع أسرارًا فيه.

## شجرة مختصرة

```text
index.js                  خادم Express، API، التخزين المحلي وخدمة الملفات
client/                   الواجهة الثابتة القديمة والبديل عند غياب build
frontend/src/
  App.tsx                 التوجيه وحماية الصفحات من جهة الواجهة
  pages/                  تسجيل الدخول، لوحة العملاء وتفاصيل العميل
  stores/                 حالة المستخدم والبيانات باستخدام Zustand
  types/                  أنواع TypeScript للبيانات والحالة
  utils/                  API، الصلاحيات، تطبيع بيانات العميل وPDF
data/                     ملفات البيانات والمرفقات عند التشغيل؛ لا تُرفع إلى Git
docs/                     أدلة المشروع التفصيلية
```

## التحقق

```powershell
cd frontend
npm run lint
npm run build
```

لا يحتوي المشروع حاليًا على مجموعة اختبارات آلية مهيأة.
