# بوابة الدلتا

## المتطلبات

- Node.js و npm

## التشغيل

1. ثبّت اعتماديات الخادم:

   ```powershell
   npm install
   ```

2. في PowerShell، عيّن بيانات المدير الأول قبل التشغيل. استخدم كلمة مرور جديدة وفريدة لا تقل عن 12 حرفًا:

   ```powershell
   $env:INITIAL_ADMIN_USERNAME = "admin"
   $env:INITIAL_ADMIN_PASSWORD = "<اختر كلمة مرور قوية>"
   $env:INITIAL_ADMIN_NAME = "مدير النظام"
   npm start
   ```

3. افتح `http://localhost:3000`.

في التشغيل الأول، ينشئ الخادم قاعدة بيانات محلية داخل `data/` ويخزن كلمة المرور بصيغة مجزأة. لا ترفع مجلد `data/` أو ملفات `.env` إلى GitHub. أعد تعيين كلمة مرور المدير من البيئة فقط عند إنشاء قاعدة بيانات جديدة؛ وجود قاعدة مستخدمين قائمة يمنع إعادة التهيئة.

لبناء واجهة React قبل التشغيل:

```powershell
npm run build
```

يبقى إعداد فحص الترخيص الحالي في الخادم كما هو في النسخة الأصلية.
